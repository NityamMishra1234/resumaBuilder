# **App Name**: JobPilot AI

## Core Features:

- Secure User Authentication: User registration and login using email/password, with secure JWT sessions for persistent access.
- Master Resume Profile Builder: A comprehensive, structured form for users to input and save all their personal, experience, education, and skill details, forming a master resume profile.
- AI Job Description Analyzer Tool: An AI tool that analyzes a pasted job description to extract key requirements, desired skills, and important keywords for resume tailoring.
- AI Resume Customization Tool: Leverages the master resume profile and JD analysis to intelligently reframe, optimize, and restructure the user's information for an ATS-optimized and human-sounding customized resume.
- Resume Preview & Export: Displays the generated resume in a clean web view and allows for downloading it as a professional, ATS-friendly PDF document.
- Generated Resume Management: A dashboard for users to view all previously generated resumes, regenerate them for new job descriptions, or delete outdated ones.

## Style Guidelines:

- A light and professional color scheme. Primary elements and interactive components use a deep, muted cyan (#1F647A) to convey professionalism and calm. The background uses an almost-white, very subtle grey-blue tint (#F0F3F4) for a clean canvas. An accent color of vibrant yet sophisticated blue (#3C64DD) is used sparingly for highlights and calls-to-action.
- All text uses 'Inter' (sans-serif), chosen for its modern, clean, and highly legible characteristics, suitable for both headlines and body content in a data-driven application.
- Clean, line-based icons for a minimal and modern aesthetic, ensuring quick comprehension and uncluttered interface.
- A modern, responsive grid-based layout with generous white space, emphasizing clarity and ease of navigation across forms and dashboards. Input forms are structured for a smooth and intuitive user experience.
- Subtle, fast, and functional micro-interactions and transitions to provide clear user feedback without hindering the perception of speed and efficiency.
